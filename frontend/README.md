# Frontend KubeEye

Frontend KubeEye - это клиентская часть приложения, предоставляющая пользовательский интерфейс для взаимодействия с бэкендом. Frontend написан на TypeScript с использованием React и Vite.

## Структура проекта

```
frontend/
├── public/                      # Статические файлы
├── src/                         # Исходный код
│   ├── components/              # Компоненты React
│   ├── pages/                   # Страницы приложения
│   ├── services/                # Сервисы для работы с API
│   ├── utils/                   # Утилиты
│   ├── App.tsx                  # Главный компонент
│   └── index.tsx                # Точка входа
├── Dockerfile                   # Docker конфигурация
├── package.json                 # Зависимости
├── tsconfig.json                # Конфигурация TypeScript
├── vite.config.ts               # Конфигурация Vite
└── README.md                    # Документация
```

## Основные компоненты

### Компоненты
- **`ClusterList.tsx`**: Список кластеров.
- **`ClusterForm.tsx`**: Форма для добавления/редактирования кластеров.
- **`NodeTable.tsx`**: Таблица узлов кластера.
- **`DashboardCharts.tsx`**: Графики и статистика.

### Страницы
- **`Dashboard.tsx`**: Главная страница с обзором.
- **`Inspection.tsx`**: Страница инспекции кластеров.
- **`Reports.tsx`**: Страница отчетов.

### Сервисы
- **`api.ts`**: Работа с API бэкенда.

## Запуск

### Локальный запуск
```bash
# Установите зависимости
npm install

# Запустите приложение
npm run dev
```

### Docker
```bash
# Соберите образ
docker build -t kubeeye-frontend .

# Запустите контейнер
docker run -p 3000:3000 kubeeye-frontend
```

## Конфигурация

Основные переменные окружения:
- `REACT_APP_API_URL`: URL бэкенда для связи с фронтендом.

## Технологии

- **React**: Библиотека для построения пользовательских интерфейсов.
- **TypeScript**: Типизированный JavaScript для улучшения качества кода.
- **Vite**: Быстрый инструмент сборки.
- **Ant Design**: Библиотека компонентов для создания современного интерфейса.
